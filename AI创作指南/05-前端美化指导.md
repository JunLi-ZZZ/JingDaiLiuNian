# 前端美化指导

本指南用于 AI 在新建酒馆角色卡项目时，指导如何进行前端界面的视觉设计和美化。参考 **镜待流年**、**角色卡示例/状态栏** 以及各卡的正则美化方案。

---

## 1. 前端界面的类型

在酒馆助手体系中，前端美化有三个层面：

```
层面1: 前端界面项目  → iframe 内的完整 Vue 应用（状态栏、面板等）
层面2: 正则替换美化   → 通过正则替换美化酒馆原生消息显示
层面3: 流式楼层界面   → 在消息楼层中内嵌的交互界面
```

## 2. 前端界面项目（index.ts + index.html）

### 2.1 基础模板

```html

</head>
<body>
  <div id="app"></div>
```

```typescript
// index.ts
import { createApp } from 'vue';

$(() => {
  const app = createApp(App).use(createPinia());
```

### 2.2 CSS 变量系统

**为整张卡建立统一的色彩体系。** 参考角色卡示例的档案机打字风格：

```css
/* global.css */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

:root {
  /* 核心色板 - 4-6个颜色即可 */
  --c-primary: #3c493f;      /* 主色：文字、边框 */
  --c-secondary: #7e8d85;    /* 辅色：未选中、次要文字 */
  --c-bg: #b3bfb8;           /* 底色：网页背景 */
  --c-card: #f0f7f4;         /* 卡片色：内容区背景 */
  --c-accent: #a2e3c4;       /* 强调色：进度条、重点 */
  
  /* 字体栈 */
  --font-main: 'Courier New', 'Microsoft YaHei', monospace;
  --font-display: 'Georgia', 'Microsoft YaHei', serif;
  
  /* 间距系统 */
  --sp-xs: 4px;
  --sp-sm: 8px;
  --sp-md: 12px;
  --sp-lg: 16px;
  --sp-xl: 24px;
  
  /* 阴影 */
  --shadow-card: 5px 5px 0px rgba(60, 73, 63, 0.16);
  --shadow-sm: 2px 2px 0 rgba(60, 73, 63, 0.1);
}
```

**色彩设计原则**：
- 选择一种主色调 → 降低饱和度用于背景 → 加深用于文字
- 强调色应该是主色的互补色或对比色
- 4-6个颜色足够，不要用太多颜色
- 命名用语义化的变量名而非颜色名（`--c-primary` 而非 `--c-blue`）

### 2.4 Vue 组件样式指南

```vue
<template>
  <div class="card">
    <div class="section-head">{{ title }}</div>
    <!-- 内容 -->
  </div>
</template>

<style lang="scss" scoped>
.card {
  width: 100%;
  max-width: 720px;
  background-color: var(--c-card);
  border: 3px solid var(--c-primary);
  box-shadow: var(--shadow-card);
  display: flex;
  flex-direction: column;
  font-family: var(--font-main);
  color: var(--c-primary);
  font-size: 13px;
  line-height: 1.35;
  margin: 0 auto;
}

.section-head {
  font-size: 0.95rem;
  border-bottom: 3px solid var(--c-accent);
  display: inline-block;
  margin-bottom: var(--sp-sm);
  font-weight: bold;
}
</style>
```

**关键原则**：
- 使用 `scoped` 属性避免样式泄漏
- 禁止使用 `vh` 单位，用 `width` + `aspect-ratio` 控制高度
- 避免 `min-height`、`overflow: auto`（会撑高iframe父容器）
- 避免 `position: absolute`（脱离文档流会导致iframe高度计算错误）
- 页面适配容器宽度，不产生横向滚动条
- max-width 控制在 720px 以内（适配酒馆消息栏宽度）

### 2.5 组件设计模式

参考角色卡示例的状态栏布局：

```
┌──────────────────────────────┐
│         WorldSection          │  ← 世界状态概览
├──────────────────────────────┤
│        DependencyBar          │  ← 进度条/状态条
├──────────────────────────────┤
│   [角色情报] [持有物品]       │  ← TabNav 标签导航
├──────────────────────────────┤
│                              │
│     CharacterPanel /         │  ← 根据标签切换的内容
│     InventoryPanel           │
│                              │
└──────────────────────────────┘
```

**组件拆分原则**：
- 每个组件只负责一个功能区域
- 用 TabNav 管理多面板切换（使用 `useLocalStorage` 持久化标签状态）
- 用 `defineMvuDataStore` 共享数据

### 2.6 iframe 适配规则（重要）

```yaml
必须遵守:
  - <head> 必须为空（webpack填充）
  - 禁止在 HTML 中使用 <link> 导入样式
  - 禁止在 HTML 中使用 <script> 导入脚本
  - 禁止 <img src="">（空src会导致webpack错误）

高度适配:
  - 禁止使用 vh 单位
  - 使用 width: 100% + aspect-ratio 控制高度
  - 避免 overflow: auto（会产生滚动条）
  - 避免 position: absolute（脱离文档流）

宽度适配:
  - 适配容器宽度（通常约600-800px）
  - 不产生横向滚动条
  - 使用 max-width 限制最大宽度
  - 移动端使用 @media 做响应式

卡片风格:
  - 适合卡片形状时不要有背景颜色
  - 圆角使用 0-4px（酒馆风格偏方正）
```

## 3. 正则替换美化

### 3.1 什么是正则替换

正则替换是在酒馆消息渲染到页面前，通过正则表达式匹配和替换来美化AI输出显示的技术。

### 3.2 实际案例：电车JC后传的正则系统

```yaml
正则:
  - 正则名称: 开场白
    启用: true
    查找表达式: <prologue987/>
    文件: 正则\开场白          ← 替换为该文件的内容
    来源:
      用户输入: false
      AI输出: true             ← 替换AI输出
    作用于:
      仅格式显示: true          ← 只影响显示，不影响发给AI的提示词
      仅格式提示词: false

  - 正则名称: 美化选项
    启用: true
    查找表达式: <options>((?:(?!<options>)[\s\S])*?)<\/options>(?![\s\S]*<options>[\s\S]*<\/options>)
    文件: 正则\美化选项
    来源:
      用户输入: false
      AI输出: true
    作用于:
      仅格式显示: true           ← 美化选项在网页上的显示效果
      仅格式提示词: false

  - 正则名称: 对AI隐藏图片
    启用: true
    查找表达式: /<img>(.*?)<\/img>/gi
    内容: ""                     ← 替换为空（隐藏）
    来源:
      用户输入: false
      AI输出: true
    作用于:
      仅格式显示: false
      仅格式提示词: true         ← 对AI隐藏，但网页上显示图片

  - 正则名称: 隐藏选项
    启用: true
    查找表达式: <options>((?:(?!<options>)[\s\S])*?)<\/options>(?![\s\S]*<options>[\s\S]*<\/options>)
    内容: ""                     ← 替换为空
    来源:
      用户输入: false
      AI输出: true
    作用于:
      仅格式显示: false
      仅格式提示词: true         ← 选项对AI不可见
```

### 3.3 正则设计模式

**模式1：占位符替换**
```
AI输出中包含特殊标记 → 正则将其替换为具体内容
用途：开场白、动态内容插入
例如：<prologue987/> → 替换为完整开场白HTML
```

**模式2：样式包装**
```
AI输出的纯文本 → 正则用HTML/CSS包装美化
用途：选项样式美化、角色对话气泡
例如：<options>...</options> → 包装为带样式的选项按钮
```

**模式3：AI隐藏**
```
AI输出中的特殊内容 → 正则从提示词中移除
用途：只有玩家能看到的内容（图片、UI元素）
例如：<img>...</img> → 对AI隐藏（替换为空），对玩家显示
```

### 3.4 正则美化选项的示例

```html

<div class="options-container">
  <div class="options-title">你可以：</div>
  $1  <!-- $1 引用正则捕获组的内容 -->
</div>

<style>

  margin: 12px 0;
```

## 4. 图标使用

```html
<!-- 使用 class 引用图标 -->
```

## 6. 响应式设计

```scss
// 基础：适配酒馆消息栏（约600-800px）
.card {
  width: 100%;
  max-width: 720px;
  margin: 0 auto;
}

// 小屏：单列布局
@media (max-width: 600px) {
  .grid {
    grid-template-columns: 1fr;
  }
  
  .card {
    font-size: 12px;  // 小屏缩小字号
  }
}

// 极小屏：简化显示
@media (max-width: 400px) {
  .detail-info {
    display: none;  // 隐藏次要信息
  }
}
```

## 7. 动画效果

```scss
// 面板切换淡入效果
.tab-pane {
  display: none;
  animation: fadeEffect 0.4s;
}

.tab-pane.active {
  display: block;
}

@keyframes fadeEffect {
  from {
    opacity: 0;
    transform: translateY(5px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

// 数值变化闪烁（如血量减少）
@keyframes flash {
  0%, 100% { background-color: transparent; }
  50% { background-color: var(--c-accent); }
}

.value-changed {
  animation: flash 0.6s ease-in-out;
}
```

**动画原则**：
- 过渡动画不超过 0.4s（太慢会让界面感觉迟钝）
- 使用 `transform` 而非 `top/left`（性能更好）
- 不要过度使用动画（每个界面1-2处动画即可）
- 避免无限循环的动画（会分散注意力）

## 8. 流式楼层界面

如果需要创建跟随消息流的交互界面，参考 `util/streaming.ts`：

```typescript
import { mountStreamingMessage } from '@util/streaming';
import StreamingApp from './App.vue';

$(() => {
  mountStreamingMessage(createApp(StreamingApp));
});
```

流式界面的样式规则与普通前端界面相同，另外：
- 内容高度可能动态变化，需要正确处理
- 避免固定高度，使用 `auto` 或 `fit-content`

## 9. 脚本中挂载 Vue 组件时的样式

### 挂载到酒馆DOM（补充酒馆UI）

```typescript
import { teleportStyle } from '@util/script';

// 禁止使用 tailwindcss（可能与酒馆样式冲突）
// 使用 scoped scss 定义样式
const { destroy } = teleportStyle();  // 复制样式到酒馆<head>

$(window).on('pagehide', () => {
  destroy();  // 卸载时清理样式
});
```

### 挂载到iframe DOM（独立界面）

```typescript
import { createScriptIdIframe, teleportStyle } from '@util/script';

// 优先使用 tailwindcss（独立空间，不会冲突）
const $app = createScriptIdIframe()
  .appendTo('body')
  .on('load', () => {
    teleportStyle($app[0].contentDocument!.head);
    app.mount($app[0].contentDocument!.body);
  });
```

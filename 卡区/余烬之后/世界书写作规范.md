# 余烬之后 · 世界书写作规范

写给接手世界书文本的协作者（主要是 Codex）。目标只有一个：让不同时间、不同模型写出来的条目，读起来像同一个人写的。

---

## 一、先搞清楚这些文件是什么

世界书条目会被注入 AI 的上下文，AI 读了它去演一个世界。**它不是给人读的设定集，是给执行者读的规格说明。**

这个定位决定三件事：

**1. 写事实，不写感受。**

- ✗ `这里的风景令人心旷神怡` —— 感受，AI 无法据此执行
- ✓ `此处地势平缓，水系发达` —— 事实，AI 知道该怎么落笔

**2. 写规则，不写场面。**

- ✗ `他会狡诈地周旋` —— 「狡诈」无法验收，AI 每次理解都可能不同
- ✓ `登场源于角色自己的需求、职责或利益` —— 可执行，能约束 AI 在每次生成时做判断

**3. 不给例子。**

一旦给出具体示例，AI 会把它当成默认答案反复复用，世界就塌缩成一个样板。写 `性格倾向影响初次见面的默认态度`，别写 `比如铁匠会先打量你的武器`。

反面教材是旧版的 `品阶.txt`：一张七阶梯子被拆成平铺段落，还混进了抒情评论。梯子是**结构**，结构必须能一眼看出层次。

## 二、结构怎么分

每个文件按**内容形态**选排版，不按「我想让它看起来多整齐」选。

**这是最容易犯的错。** 判断依据是"上一处怎么改的"，而不是"这段内容属于哪种形态"，结果会在同一批次里出现方向相反的改动 —— 一边给 A 文件删空行、一边给 B 文件加空行。这证明决定来自惯性，跟内容无关。

三种形态，三种排法：

### 定义 / 尺度类
条目内部不空行，条目之间空一行。

```yaml
    凡尘：本质明晰，法则作用直接，为该位面常见的力量层次。作用条件明确，可及性高。
    凝华：结构稳定，效率优于寻常，具备可靠的实用价值。
    罕世：具备稀缺条件或独特作用，能够解决常规手段难以处理的问题。
```

适用：`品阶.txt` 的七阶梯子、`原初本源.yaml` 的八个顶层组、神器的 `外观与特征`。

### 列表类
列表项之间不空行，段与段之间空一行。

```yaml
超凡规则:
  - 超凡存在默认不惊扰凡人
  - 普通人接触超凡现象后自然淡忘或合理化
  - 故意大规模暴露引天道反噬。过强外来力量被世界意志压制
```

注意这个例子里，三条列表项**是同一个段**，所以项与项之间不空行。如果两份列表分属两个不同的段（比如 `超凡规则` 和 `身份与隐匿`），两段之间空一行。

适用：`主世界.txt` 的 `超凡规则`、`能力进化.txt` 的约束列表。

### 公式类
公式独占一行，周围用文字解释，公式本身不掺进句子里。

```
伤害 = (攻击×能力倍率 + 固定伤害) × 暴击倍率 × 100/(100+防御) × (1-机制抗性)
```

**公式绝不能用左结合的散文转述。** 写成「100除以100加防御」在数学上完全是另一回事 —— 那不是简写，是错误。

适用：`战斗与检定.txt`。

## 三、层级与键名

**能用键值就不用长段落。** 一个平铺段落里塞进七八个信息点，AI 分不清主次。

**同级键名要同构。** 六件神器的键名规则：

| 类别 | 键名格式 | 例子 |
|---|---|---|
| 平砍 | `基础攻击-<名>:` 或 `基础攻击:` | `基础攻击-法则弹:` / `基础攻击:` |
| 被动 | `被动效果-<名>:` | `被动效果-收割印记:` |
| 主动 | `主动技能-<名>:` | `主动技能-誓言结界:` |
| 觉醒解锁 | `进阶能力-<名>:（觉醒后解锁）` | `进阶能力-虚化斩击（觉醒后解锁）:` |
| 终极 | `特殊能力-<名>:` | `特殊能力-绝对守护:` |
| 联动 | `神器联动-<名称>:` | `神器联动-轮转之环:` |
| 线索首项 | 一律 `最后记录:` | |
| 器械共鸣 | 一律 `神器共鸣:` | |

同构的价值：AI 扫到 `主动技能-` 就知道这是要花储能、有冷却的东西；扫到 `被动效果-` 就知道自动生效。**键名是给 AI 的分类信号，不是装饰。**

反例（已修）：归一原来写 `神器联动枢纽:`，六件里唯一没有 `-<名>` 后缀的；永誓有 `转化防护:` 和 `符石充能:` 两个裸键，同级其他全是带前缀的。

**别让同类键被异类夹开。** 轮回原本把两个 `被动效果-` 分在 `基础攻击:` 两侧：

```
被动效果-收割印记:
基础攻击:          ← 夹在中间
被动效果-生命汲取:
```

读起来像三种并列。同类归堆，改成：

```
基础攻击:
被动效果-收割印记:
被动效果-生命汲取:
主动技能-终结收割:
```

## 四、句式禁令

### 禁止 `不是……而是……`

这个句式在设定文里出现频率极高，因为它省事 —— 一次否定加一次肯定就把定位说清了。但读多了会让整篇文本变成同一个腔调，而且它在逻辑上偷懒：绕着说 A 不对，才说 B 是什么。**直接写 B。**

- ✗ `这不是装饰，而是法则作用范围的视觉化`
- ✓ `它是法则作用范围的视觉化`

- ✗ `它理解死亡不是终点，而是下一次生命的起点`
- ✓ `它理解死亡是下一次生命的起点`

- ✗ `这种失衡并非某个存在的主动选择，而是世界发展的自然趋势`
- ✓ `这种失衡是世界发展的自然趋势`

**省略逗号的变体同样算。** 扫的时候别只搜 `不是…而是…`，这两种也会漏：

- `不…而是…` —— 例：`能力不会立即消失而是进入"合成状态"`
- `不等于…而是…` —— 例：`这不等于疏远或冷淡，而是完整个体的自然状态`
- `属于…而是…` / `没有…而是…` 等，凡是否定分句后接 `而是`，一律算

**扫法：直接 grep `而是`，不限定前缀。** 这条是最容易漏的，用窄模式搜会误报"已清完"。

**不算的例外 —— 行文里的排比划界：**

- ✓ `深情不等于痴狂，专一不等于排他，亲近不等于依附` —— 三句同构的排比，是刻意的文字设计，末句不接 `而是`
- ✓ `传闻不等于事实` —— 独立断言，不是对比句式
- ✓ `崩碎的本源力量没有消散，而是凝聚成六件原初神器` —— 「没有消散」承载实质信息（否定了一种预期），不是修辞垫脚

判据：后半句的 `而是` 是在**替换一个被否掉的错误认知**（改），还是**承接一个实质事实的转折**（留）。

### 禁止用破折号做解释

`某片区域的规则与周围明显不符——无法用当地力量体系解释` 这种写法把解释挂在破折号后面，读起来像补丁。用句号断开，或直接取消解释。

**三件神器原本共用同一个模板句**（`表现为"术语"——某片区域的…`），既是破折号解释也是模板复用，已分别改写。

**例外：** 破折号用于引语收束或情感停顿是正常行文，不要一刀切。

- ✓ `她得出了一个简单而错误的结论——只要重伤末墟，终末之力就会衰退`
- ✓ `回荡着她困惑而委屈的低鸣——她不理解为什么自救会遭到阻止`

判据：破折号后面是**解释一个术语**（改），还是**引出说话/情绪内容**（留）。

### 别为了躲特殊字符硬造别扭写法

归一原来写 `1加1大于2`，是为了避开 `>` 在 YAML 里的歧义，结果是句人话都不像。改写成 `超越简单相加` 即可。

### 避免 `而非` 做对比收尾

`源于角色自己的需求，而非为填补剧情空白` —— 后半截是多余的。前半截说清了，AI 自然知道不该那样做。

真需要排除某个误用时，写成正面约束：

- ✗ `源于角色自己的需求、职责或利益，而非为填补剧情空白而存在`
- ✓ `源于角色自己的需求、职责或利益，剧情空白不构成角色出现的理由`

### 词汇贴合世界观

用词要匹配位面文化。西幻位面禁用东方词（姑爷、府、宫），东方古风位面反之。这条容易在跨位面的文件里翻车。

## 五、改之前先自问

1. 我删/加这个空行，是因为**这段内容属于另一种形态**，还是因为**我上一处也这么改了**？
2. 这个键名 AI 扫到会归到哪一类？和它的兄弟键同构吗？
3. 这句话是事实还是评述？**评述一律删。**
4. 这个例子会不会被 AI 当成默认模板？会就别写。
5. 有没有 `不是…而是…` 和解释性破折号？

**第 1 条是重点。** 之前那轮批量修改最根本的失误，就是拿"上一处怎么改的"当依据。

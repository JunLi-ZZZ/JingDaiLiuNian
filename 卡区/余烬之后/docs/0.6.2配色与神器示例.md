# 0.6.2 · 品阶配色与长枪示例

本轮基线为 Git 926b46f1（0.6.1）。修改范围仅为余烬之后的显示样式、对应验收与文档。

## 配色

凡尘白银、凝华绿、罕世蓝、史铭紫、传遗黄、神御红、本源橙、原初本源粉彩虹。参照镜待流年的渐变文字呈现，品阶字和正文卡标题流动，卡面使用同色系浅底。边框、纹章、数值强调与之呼应，正文使用深色。白色与黄色文字使用细描边保留轮廓。

八种主题共用于能力、物品和带序列的档案；不同类型保持各自布局。品阶名称、数据字段和计算不改。减少动态效果时关闭文字动画，系统强制颜色时显示普通文字。

预览：运行 npm run preview 后打开 /cards，选择“本质序列”。本次留给用户的预览地址为 http://127.0.0.1:8142/cards 。

## 神器与实验

候选稿：[定澜](design/神器示例-定澜.yaml)，以长枪为原型，核心为支点与动势。配套[作者说明](design/神器示例说明.md)记录设计目的、候选参数及后续接入边界。

稿件暂存 docs/design，未进入世界书清单或卡包提示词。现有神器体系的“六件完整”与“数量可扩展”需在正式接入新神器时统一。

已查看另一会话光栅卡实验中溯寂的两张原画预览，并打开交互网页观察自动转动效果。未修改实验资源、运行生图或接入正式构建。其视觉样品文字不视为已确定的世界书设定。

# 0.5.4：EJS作用域修复与下一轮交接

日期：2026-09-23。本版是0.5.3运行修复；新虚海背景与多能力开局尚未集成，按用户确认先交给Claude编写文本。

## 故障与修复

用户截图：`Identifier 'library' has already been declared`，发生于EJS编译阶段。位面与资料库控制器均在顶层声明library；开局与成长控制器也重复声明state/actor，变量列表与其他控制器重复声明recent。

用本地提示词模板扩展的真实EJS编译器复现：两条控制器分别编译通过，组合编译报同一library错误。给六个控制器与生成的变量列表分别加块作用域，保留异步getwi与原路由。修复回写tools/generate.cjs，避免重生成覆盖。

成长控制器同时将固定第3楼查询改成最近三楼（-3、-2、-1），与其原本的近期条件含义一致。

## 验证

tests/ejs.test.cjs先在旧代码上失败，再在修复后通过，覆盖全部启用EJS合并/重复编译、首轮与日常路由、初始空状态、生成位面的指定世界书读取，以及成长条件。tools/ejs-check.cjs接入pack，在发行写入之前检查组合语法。

真实EJS编译器验证7个模板分别/合并/重复编译通过。该编译器位于E:/st-main/ST-Prompt-Template-main/src/3rdparty/ejs.js；新增常驻回归测试采用本卡语句块提取与JavaScript异步函数编译，不依赖外部扩展路径。以后增加其他EJS标签时检查器会报错，需同步扩展验证器。

完整pack通过类型检查、120项行为测试及PNG负载/原头像图像块回读校验（43条世界书）。结果见tests/logs/pack-0.5.4.log。本轮未改前端布局，未重复执行三组前端视觉测试。

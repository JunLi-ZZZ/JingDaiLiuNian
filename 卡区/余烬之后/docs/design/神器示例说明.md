# 定澜 · 长枪候选稿

这份稿件用于本轮比较神器文风与玩法，尚未登记为正式世界书条目。全文见同目录《神器示例-定澜.yaml》。程序、既有开局和神器数量不随此稿改变。

## 设计意图

以“存在的锚定与诸界动势”连接枪术、守援和跨界。虚海为容纳位面气泡的无垠虚空。枪的形状本身参与玩法：枪尾落点，枪杆承载与拨转，枪尖送出力量。初始能力有明确使用尺度，深层解放从经历和实际用法发展。

本稿已按2026-09-26反馈重写，去除反噬与弱化持有者的副作用，以神器储备与解放程度确定调用规模。具体数值在正式接入时按当前形态定标，余势转存、锚定与跨界联动尚未接入计算。单独的神器效果留在自身条目，不进入所有能力的通用规则。

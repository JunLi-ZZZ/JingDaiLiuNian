# 余烬之后 0.5.1 本地测试

卡包：release/0.5.1/余烬之后-0.5.1.png。卡名和世界书名均为“余烬之后 v0.5.1”。导入卡片及其内嵌世界书，启用本卡脚本和正则，另开新聊天测试。旧聊天和0.5.0产物保留；本次不自动迁移在线聊天。

## 这次观察什么

1. 默认开局后发送一段交谈，查看“变化”：游戏时间应按剧情经过秒数增加；首次人物资料应能打开。主角身份卡直接读取封面人设。
2. 第二轮交谈或行动后检查时间、场景及变量保存提示。状态栏现在区分“有更新文本”和“已处理”；截图时请保留具体报错和原始变量块。
3. 重构完成后再旅行、接触危险或使用能力。对照正文卡片与状态栏的生命、能量、储能、冷却，确认同一件事的结果一致。
4. 发生校验错误时仍可局部修复报错字段；确认保存前可预览。刷新、重复解析不应重算已保存的同一回执。

## 本轮变化

接入 Fable5 的四篇适用规则及格式修订；修复漏打包、悬空条目和字段名称不一致；增加对象包装变量兼容、主角档案读取和保存回执提示。
死亡复苏的文本及专属程序集中于独立起源涅槃目录。装备/遭遇误用的参考稿移出卡包。通用能力、成长、品阶和人物/位面机制继续共用。

## 计算分工

本卡已有计算内核，生命变化、命中/暴击、攻防抗性、转化储能、能量消耗、冷却、D20、等级熟练与进化、时间和复苏均由脚本处理。AI提供行为、对象、条件与参数。

## 世界与神器

虚海指容纳位面气泡的无垠虚空。“海”是浩瀚的比喻，各位面内部自成时空与法则。核心条目、角色关联、起源涅槃开局、封面场景和生成提示词按这一含义统一。归泊庭是由界膜包裹的独立微型界域，白石阶与廊屋悬于虚空。本土位面的真实海洋及其生态仍按本土设定存在。

定澜候选改以诸界坐标与动势为核心，枪锋共享跨界落点，深层权能能锚定位面结构。储备和共鸣决定可调用规模，神器通过自身本源恢复。原初神器条目中损伤持有者、强制虚弱、心智侵蚀及强迫维护的内容已整理为神器储备与自主循环。

定澜仍位于 docs/design，尚未注册为第七件正式神器。已有六件、未知碎片与完整融合的进一步设定，应在正式扩充神器时一起核对；本轮不宣称这些候选权能已全部进入数值执行器。

## 同伴与附近的人

界面分组依据关系与场景，不依物种。同伴保存持续关系；附近的人保存当前交互对象。两页均展示生命、能量、攻击、防御，展开可见命中、闪避、暴击与倍率，并可直接加入同伴或移至附近的人。

人物首次建档填写“属性”，脚本自动建立同 ID 的数值实体和基础攻击。正文人物卡与状态栏读实体实时值；后续叙事重复提交旧的初始数值不会治愈或重置资源。实体 ID 仍可关联旧数值档案。未提供分组的新建档案默认进入附近的人；旧档保留同伴归类，可手动迁移。

旧角色缺数值时，在角色详情中点击“补全此角色属性”。只生成这一人的属性，允许补充依据和编辑候选，核对后保存。生成调用酒馆当前模型。预览不写存档，取消、聊天切换和过期快照不会把候选写入新状态。手动属性补建与分组操作跟随本楼原文回执，重解析可恢复；已有数值状态仍走结算内核。

附近的人离开场景后不再自动进入人物、实体、相关见闻和关系投影；已保存世界书的 EJS 调用也遵循这一筛选。完整资料仍在存档，通过“查看已离场档案”查阅并可转回同伴。每轮详细档案最多 8 份，同伴名称索引最多 48 项，并显示总量；查询相关同伴可调入详情。这些是提示词投影上限，不是存档容量。

## 光栅卡

按光栅卡实验/八阶规范的接口和纹样，独立抽取界面/shared/grade-materials.ts、grade-ornament.ts 与 HoloSurface.vue。实验原文件保留原样。

正文能力、获得能力和物品卡，状态栏能力与行囊，使用八种文字光栅材质。人物与场景保留自己的信息结构；无已知品阶时使用中性外观。所有文本和数值来自原档案，卡面材质不增加 AI 输出字段。

桌面指针驱动轻微倾斜与反光，触屏可点击“转动卡面”。提供暂停、减少动态偏好和离开可视范围/页面后台停止动态；触屏纵向手势用于滚动。当前接入不需要图片、远程素材或 WebGL。带照片的神器专属卡继续由后续素材接入。

## 验证与边界

行为测试覆盖人物自动注册、同轮时间与攻防、旧数值不重置、分组双向迁移、离场投影、EJS 路由、手动属性补建及同楼回放。浏览器检查覆盖卡片展开、属性补全预览保存、转移、清理恢复与窄屏。最终执行结果见同版本测试说明。

本地浏览器测试使用模拟酒馆接口，不代表真实模型每轮都会正确填写字段。世界书文字与生成质量仍需实际游玩验证。真实聊天与其他卡的构建、升版和工作区文件不在本轮操作范围。

# 0.6.3 测试入口

1. 在 /cards 的“本质序列”查看八种文字卡材质，移动指针或点击“转动卡面”，再试暂停光效；展开物品卡核对完整文字。
2. 在酒馆进入同伴或附近的人，核对生命、能量、攻防和展开后的概率属性，双向转移一个角色。
3. 对旧档缺属性的角色使用“补全此角色属性”，核对候选后保存。让 AI 更新后再查看，确认原有伤势和消耗没有恢复为初始值。
4. 附近的人离场后从常用列表退出，通过“查看已离场档案”仍能找到；同伴暂别后仍可查阅。
5. 新开局查看归泊庭和虚空位面意象。历史聊天正文不会被批量重写。

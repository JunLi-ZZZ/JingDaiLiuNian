# 0.5.3 本轮变更与验收

日期：2026-09-22。

## 使用入口

导入 `release/0.5.3/余烬之后-0.5.3.png` 及其同名世界书。历史发行保留，其他卡构建与发布未改动。建议新聊天测试完整建档；旧聊天空字段需由后续模型更新补全，程序不会替模型编写人物身世。

## 实际改变

- 随机：移除当前状态中的32组骰列，确定性伪随机仍由脚本执行。事件回放保持结果，跨分支/版本/序号变化。正文在尝试处引用结果卡，后续读取结算结果。
- 见闻：自动选择近期/场景/提及内容，加上手动优先项，最多10条。按钮改为优先查阅，选择持续至取消。修复EJS把固定第2楼当作最近两楼的错误。
- 数值：新增register，依据背景为任意人物/生物登记生命、能量、攻防、概率和抗性，实体ID与叙事人物档案连接。保留已有伤势和消耗，重复登记沿用存档。同轮可先登记再攻防；能力获取与使用共用原内核。
- 潮镜：读取绑定世界书核心及本次相关完整设定，包含EJS管理的关闭源条目及已登记聊天世界书资料；不执行控制器代码、不切换条目启用状态。任务请求关闭无关历史/深度变量规则注入。
- 长期资料：移除固定玩家相识状态和当前动作要求，位面改为长期矛盾与地点互动条件；导出人物档案去除当前地点、近况、关系进度、即时知识和当轮动机。来源位面由来源世界查回，不采用当前所在位面。
- 全知建档：以原设定为依据，未给出的基础信息由作者合理创作补全；补全后延续事实，人物知情与正文揭示另外处理。旧档案仅补缺失字段和本轮变化。
- 视觉：七阶分别作用于能力/物品卡面、纹章、边框、标题与标签；纯描述人物标签保持普通字体。保留系统减少动态效果设置。

## 验证范围

118项行为测试、类型检查、Lint；三组浏览器测试覆盖卡片/工坊、进化/修复、PNG封面/状态栏入口与名字解析。新增测试覆盖NPC定标后同轮战斗、带伤资源、重复建档、非玩家能力消耗、离线伪随机、见闻优先与EJS最近楼层、世界书源条目读取和稳定设定导出。

浏览器测试使用模拟酒馆接口与模型返回，不调用在线模型。文本创作质量和长线剧情一致性仍由实际游玩确认。截图位于build/verification/0.5.3，日志位于tests/logs；这些本地产物不进入Git。

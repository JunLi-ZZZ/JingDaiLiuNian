# 0.5.2 测试说明

日期：2026-09-22。此版本单独打包，保留 0.5.1 历史产物。

## 本轮变更

- 默认开局姓名从酒馆 `{{user}}` 解析，封面、开局要求、主角档案和实体使用同一名字。自定义姓名保持可编辑；既有聊天不自动改名。
- 主角正文卡合并身份与生命、能量、攻击、防御，正文协议仅使用 `character/player`。旧正文的 `entity/player` 仍能读取。
- 只有七阶品阶进入渐变样式。人物的“旅途中的你”等描述保留普通文字颜色，修复标题透明。
- 特殊按钮提示词入口汇总在 `特殊生成提示词索引.md`。世界书内容补充继续通过 Fable5 交接。

## 骰列说明

每轮的当前状态提示词会包含 32 组 D20、命中与暴击骰值。分支、结算版本与操作序号决定骰值，读取同一存档不重新投骰；只有检定、命中和暴击等操作才使用相应骰值。正文检定卡在对应事件发生并被正文引用时显示，并非每轮强制显示。

本轮未更改投骰机制。伤害与资源等仍由回复后的脚本结算；预给骰值不等于复杂行动已经全部预结算。相关入口为 `src/prompt-view.ts`、`src/prompt-format.ts` 与数值执行器。

## 用户验证

导入 `release/0.5.2/余烬之后-0.5.2.png`，使用其同名世界书，新建聊天。默认身份应显示当前酒馆用户名字；发送开局后，主角档案和正文人物卡应保持同名。自定义身份仍可填写另一姓名。

此前正文已生成的双卡标签不会自动改写。新版本规则作用于新生成内容。若继续旧聊天，存档原姓名保持不变。

## 自动验证

实际通过：112 项回归、类型检查、Lint、三组浏览器测试（正文卡/工坊、进化/局部修复、最终 PNG 的开局与状态栏入口）。覆盖 1280/390/320 宽度；核对人物标题计算样式、合并数值、默认 persona 名写入、自定义名保留与宏未解析回退。打包核验 43 条世界书、PNG 内 JSON 和原头像图像块一致。测试日志位于本地 `tests/logs/`，浏览器截图位于 `build/verification/`。离线测试不代表在线模型叙事效果已验证。

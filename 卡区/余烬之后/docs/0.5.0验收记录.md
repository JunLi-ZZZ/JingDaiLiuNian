## 验证范围

浏览器用模拟API验证交互与写回，没有调用付费在线模型，也没有向用户真实聊天保存内容。模型生成的文学质量、具体预设适配、长期剧情体验需实际游玩判断。千条档案测试验证提示词工作集上限，并非已进行一千楼真实对话。

Webpack报告内嵌自包含页面体积提示；原头像按用户要求完整内嵌。没有为了压缩体积替换头像。当前包约19MB（PNG中包含卡数据版本封装与自包含前端），精确大小以最终文件为准。

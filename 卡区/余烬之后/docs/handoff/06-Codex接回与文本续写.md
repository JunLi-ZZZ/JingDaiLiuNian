## 下一轮请 Fable5 审稿

1. 检查本轮通用/专属边界拆分后的行文衔接。不要把当前开局的奖励、身世、死亡重构重新写入通用能力或日常更新规则。
2. 故事基调“每一段关系都从陌生或疏离开始”会覆盖自定义旧识、伴生关系，应以已发生关系为起点。只写通用原则，不追加针对每个角色的例外。
3. 叙事规则“索引名及其构词一律不出现在正文”与能力名/品阶正常出现存在冲突。区分技术 ID 与角色能够认识的名称，保持正文自然。
4. NPC 生成“见习者不持传说装备、年轻人不通晓古早秘闻”把身份变成硬上限；改为经历、来源和知情依据自洽的通用原则。
5. 起源涅槃中的极端因果举例尚没有对应“适应失败”执行器。请先与 Codex 明确契约，再决定如何表达；不要将特殊效果写成已被脚本自动执行。
6. 规则仍有多处禁令、具象枚举及重复说明。按用户已有要求统整，避免把纠错过程写进世界书。技术格式骨架可以保留明确的 XML/JSON 语法。
7. 正文应从存档与已确认结算表现后果；当轮尚待计算的准确伤害由正文卡片展示。可讨论更顺畅的叙事指导，不让模型重复手算完整公式。若想让 AI 在生成同一段正文前得到复杂行动的确切结果，需要先设计预结算/工具调用流程，不是文字补丁。

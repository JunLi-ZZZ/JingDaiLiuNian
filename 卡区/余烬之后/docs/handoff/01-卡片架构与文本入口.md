# 01 · 卡片架构与文本入口

本文路径均相对卡片根目录。先读HANDOFF.md中的当前任务和用户要求，本文说明现状，不等于设计的每个部分都已完善。

## 世界与游玩循环

虚海承载开放多元位面；起源之母初微与终焉之母末墟共同维持生灭。默认主角由双方力量交融而生，在主世界以普通人的身份成长。默认事故是车辆撞击，起源涅槃首次触发、终焉眷引生效、越界形成；自我在归泊庭等待十分钟游戏基准时间重构，之后选择下一世界。自定义角色与自定义场景可以改变身份、来历和第一幕。

起源涅槃根据致死因果生成适应，世界继续运行。当前引擎主要用机制转化/储能实现适应的数值部分；这不表示宇宙中能力只有这一类。终焉眷引使防护后的剩余伤害乘1.25。已登记生命、资源、冷却与场景决定数值结果。

普通获取通过acquire登记学习、训练、天赋、传承、契约、改造等能力，人物可以use/check/strike/channel/release/train。品阶共七阶，等级和熟练独立；5/10/15级积累进化机会。进化按钮调用当前酒馆模型，根据能力、经历与场景生成主题、用途、代价和计算结构，玩家可重拟或选择。旧枚举分支留给旧记录兼容，新UI没有固定分支菜单。当前计算结构仍存在局限，必要时提出扩展，而不是把它包装成完整世界法则。

封面与正文状态栏分离。状态栏折叠后占一行，展开可查看能力、行囊、人物、见闻、归来、潮镜、行动和变化。正文有能力获得、攻防、检定、归泊、成长、人物、物品、旅行/任务记录。设定工坊生成完整人物/位面档案，用户可少填或不填，可编辑、导出并保存到聊天世界书，后者关闭后由EJS调用。

货币与商店是用户后续目标，目前没有完备实现。任意多目标、治疗、持续状态、装备自动汇总和通用物品/任务操作仍有执行器空缺。开放能力文本可以表达用途，但生命/资源变化必须有对应计算路径。

## 数据流

1. 封面按choice建立初始快照（src/opening.ts），写回首楼并发出用户开局请求（src/opening-request.ts）。
2. 初始快照已经含默认事故死亡、越界、重构与账本。AI首次回复负责当前场景叙事与人物/见闻/关系建档，新的耗时和行动另行提交。
3. EJS读取stat_data并生成模型上下文。世界书条目经tools/worldbook.cjs绑定本版本书名。关闭条目getwi后的实际位置由控制器决定。
4. AI回复包含正文、小卡引用、变量更新块、状态栏标记。
5. 公共MVU先解析模型更新；脚本/变量结构/index.ts监听COMMAND_PARSED与VARIABLE_UPDATE_ENDED，执行本卡acceptNarrativeUpdate。
6. src/mvu-policy.ts规范化本轮时间/动作，对照Schema校验，调用src/engine.ts原子结算。失败保留旧状态、_更新错误、_待修复，成功保存账本与回执。
7. 前端读取当前楼层MVU数据；卡片引用类型和ID经src/output-cards.ts取档案；无法取到则显示“档案待同步”。
8. 变量修复用原失败批次和报错路径请求局部补丁，经预览确认写回同楼变量与正文更新块。没有解析到任何操作时不一定会形成_待修复，这是本次P0代码待办。

## 状态和约束

| 内容 | 位置/责任 |
| --- | --- |
| 正式结构及动作参数 | src/schema.ts：Schema、MvuInputSchema、OperationSchema |
| 运行时权威数值 | _实体、_能力、_物品、_任务、_时空、_复苏、_死亡记录、_结算；脚本维护 |
| 模型可写叙事 | 叙事：天气、场景、见闻、人物、关系、事件、摘要、时间、动作、首次完成 |
| 选择前的方案 | 待审提案 |
| 原子操作 | src/engine.ts，失败回滚整批；相同事件重放不重复扣费 |
| 紧凑状态视图 | src/prompt-view.ts筛选，src/prompt-format.ts可读格式 |
| 错误局部修复 | src/variable-repair.ts、界面/状态栏/Regenerate.vue |
| 当前身份 | _开局.档案；变量列表把酒馆宏{{user}}映射到本局角色；player为稳定ID |
| 已有能力与原生人物档案 | 不同表；_实体.player存在不代表叙事.人物档案.player存在 |
| 资料库与工坊 | src/library.ts、src/workshop-model.ts、界面/状态栏/Workshop.vue |
| 成长/进化 | src/progression.ts、src/evolution-generation.ts、界面/状态栏/Evolution.vue |

模型提交的本轮时间是当地额外秒数，本轮结算是对象数组或null；代码规范为包含起算版本的对象。攻击/训练带有自身耗时。省略、空对象与null的语义以schema与代码为准。模型只回顾已写入历史时不应再次执行历史操作；该原则需在提示词中用简洁正向描述表达。

## 自动生成文件

世界书/变量/变量列表.txt由src/prompt-view.ts和src/prompt-format.ts序列化生成；世界书/系统/操作字段契约.txt由src/operation-guide.ts及OperationSchema生成；世界书/变量/initvar.yaml来自src/presets.ts；世界书条目清单.yaml来自tools/generate.cjs与src/worldbook-order.ts。generated/内JSON也由generate生成。

这些文件即使直接改了也会被下次generate覆盖。Fable5可在回交文档给出所需文本/结构，交Codex修改生成源；若直接改源代码中的文字，需保留函数、字段和插值合法。

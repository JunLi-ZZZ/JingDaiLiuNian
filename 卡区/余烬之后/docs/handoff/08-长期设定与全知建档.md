# 0.5.3 长期设定、全知建档与数值登记

本轮按用户明确反馈修订。镜待流年的经验用于字段完整、人物辨识度、可变细节与背景的分层；红颜专属关系及任何固定初见剧情不迁入潮镜。

文本目标：潮镜输出可长期复用的世界书基础设定，人物的当前地点、正在进行的动作、玩家相识状态放本局变量。位面资料描述地理文明、历史和长期矛盾，互动机会采用条件而非固定正在发生的事件。角色缺失资料由作者依据世界、种族、职业和经历合理创作，一次建立、后续延续；完整作者资料不等于人物自动知道。

技术配套：移除常驻骰列，脚本仍按分支/版本/操作序号确定性结算；新增 register 操作按稳定 ID 登记任意人物和生物的生命、能量、攻防与概率，沿用通用攻击/获取/成长内核。人物档案以实体ID链接数值。旧 encounter 保留兼容。重复登记保留已有伤势与资源。

生成上下文：只读取当前卡绑定世界书的核心、创作原则和本次相关的完整设定，以及已登记潮镜条目。关闭的位面/人物源条目可显式读取；不执行控制器源代码，不改变启用状态。正常剧情仍由原 EJS 控制器调用这些条目。

Fable5 后续审稿范围：人物档案、首次/日常更新、战斗与检定、行动与结算，以及 src/workshop-model.ts 中的专属生成文字。保持字段与程序一致，通用规则用正面指令，原设定优先；补全形成作者事实，正文按各人物知情与当下场景表现。

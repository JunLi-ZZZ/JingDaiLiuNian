# 主角卡协议与特殊提示词入口

本轮只修订了正文卡的技术引用协议，故事设定未扩写。

`世界书/系统/正文格式.txt` 与 `人物档案.txt` 现统一主角 `character/player`，程序从开局档案与实体合并身份及核心数值。NPC 仍按叙事人物档案引用，已辨明数值实体沿用 `entity`。

Fable5 后续审稿请维持这套读取关系，同一对象使用一张资料卡。更自然的表述可以调整，字段、标签与 ID 来源保持一致。

按钮调用模型的文字不在世界书中。入口详见 `../特殊生成提示词索引.md`；角色/位面档案由 `workshopPrompt()` 组装，进化由 `evolutionPrompt()` 组装，局部修复由 `repairPrompt()` 组装。若希望调整这些提示词，先提出具体文字差异，由 Codex 同时核验解析结构、调用上下文及确认步骤。

默认主角名现在从酒馆 persona 宏解析并固化为本局姓名；自定义姓名沿用既有“本局 {{user}} 就是…”身份映射。

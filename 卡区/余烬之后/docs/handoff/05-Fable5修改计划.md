## 五、修改原则

参考镜待流年的写法：
1. **不举例**：说原则不说场景
2. **不用禁止项**：说应该做什么，不说不该做什么  
3. **不给具体数值**：说"按威胁程度定强度"而非"杂兵30-60生命"
4. **通用化**：适用所有情况的原则，不是场景补丁

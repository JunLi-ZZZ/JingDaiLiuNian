# 余烬之后：结算闭环演示

由 npm run demo 生成。固定输入用于检查程序行为，不是玩家已发生的经历，也不是正式平衡方案。

测试规则：主角生命 100、雷兽生命 200、攻击强度 120、复苏耗时 600 起源秒、当前位面时间倍率 1。

| 步骤 | 结算 | 主角生命 | 本地时间（秒） |
| --- | --- | --- | --- |
| first-death | 死亡已确认，获得电荷转移，开始重构 | 0 | 0 |
| world-continues | 世界时间推进600起源秒 | 0 | 600 |
| revival | 复苏完成，外界经历与掉落物保留 | 100 | 600 |
| same-attack | 实际损伤0，剩余生命100 | 100 | 600 |
| release | 实际损伤120，剩余生命80 | 100 | 600 |

- 雷兽剩余生命：80。
- 截止时间为 300 秒的任务：已失效。
- 旅行包仍在：square（地点）。
- 死亡记录：1 次；已获得能力：1 项。
- 全程没有调用模型、改写酒馆存档或修改其他卡。

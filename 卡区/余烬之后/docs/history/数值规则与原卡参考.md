## 当前数值

| 字段 | 单位与用途 |
| --- | --- |
| 生命.当前 / 上限 | 明确的生存额度，伤害扣至 0 时死亡；未定标为 null，不等于死亡 |
| 资源 | 独立 ID 的能量、灵力、体力、适应储能等；各有当前值/上限，不互相代扣 |
| 战斗.攻击 | 技能基础伤害的来源 |
| 战斗.防御 | 连续减伤，100 防御使伤害减半 |
| 战斗.命中率 / 闪避率 | 0～1，显示为百分比 |
| 战斗.暴击率 / 暴击倍率 | 0～1 与倍率；例 0.2、1.5 表示 20% 几率、1.5 倍伤害 |
| 战斗.抗性 | 按机制 ID 保存，-1～1；负值为弱点，1 为该机制免伤 |
| 能力.消耗 / 冷却本地秒 | 资源消耗映射与当地游戏秒的冷却 |

`属性` 动态字典保留给其他已登记属性，不与固定 `战斗` 面板重复写入同一项。尚未配置 `战斗` 面板的角色不能参加这版攻防结算。普通 NPC 可先只有叙事档案，进入战斗前再定标；没有自动套用默认主角数值。

## combat-1：直接攻击基础

1. 校验双方存活、生命与战斗面板、同场景、技能所有权、效果类型、冷却和资源。
2. 命中概率 = clamp(攻击者命中率 - 目标闪避率, 0, 1)。脚本随机数落在 [0, 1)，严格小于概率才命中。
3. 命中后单独判定暴击；未命中不取暴击随机数。
4. 基础伤害 = 攻击 × 技能倍率 + 固定伤害。
5. 待适应伤害 = floor(基础伤害 × 暴击倍率 × 100/(100+防御) × (1-对应抗性))。非暴击倍率为 1；不设强制最低 1 点伤害。
6. 适应能力转移对应机制的伤害；剩余部分扣生命，最低 0。多余伤害不会令 HP 变负。
7. 生命归零才生成死亡记录、能力奖励和复苏事务；不接受正文先写死亡再倒填数字。

技能采用 `combat-strike-1` 效果，参数为 `机制ID`、`倍率`、`固定伤害`、`耗时本地秒`。整次攻击的耗时推进游戏时钟，消耗能量，冷却从行动结束算起。未命中也付出这些成本。校验失败不提交任何状态变更；成功事件保存随机结果与数值明细，同一 ID 重试直接读取原结果。

攻击 144、防御 20、倍率 1、无暴击和抗性时：`floor(144 × 100/120) = 120`。预览主角生命 100，首次雷弧致死；复苏后相同雷弧被已获得的能力转移。主角凝力一击使用攻击 30、倍率 2，面对防御 30 的巡雷兽，普通命中伤害为 46，暴击为 69，消耗能量 10，耗时 6 秒，冷却 12 秒。

这些数值是验证规则用的样本，不是正式种族平衡。复苏目前恢复生命，保留已经消耗的普通能量，不免费回满能量。适应主动释放仍使用 `trial-1` 的储能转移规则，它不是普通攻防技能，也尚未纳入完整动作经济。

速度/先攻、回合行动额度、距离和射程、多目标、护盾、治疗、持续伤害、控制、环境致死机制以及装备自动汇总仍未实现。现阶段检测到尚未支持的状态效果会拒绝攻防结算，不悄悄略过。直接伤害指令 `damage` 保留作可信环境规则与测试的底层入口，不能把模型提供的任意伤害直接交给它。

## 正文卡片约定

新卡的已结算战斗引用：

```text
<DACombat>{"分支ID":"preview","事件ID":"preview-1"}</DACombat>
```

`output-cards.ts` 严格解析 JSON 引用，从相同存档的事件账本取数据；拒绝不存在的事件、其他分支和额外的伤害字段。`BattleCard.vue` 通过 Vue 文本插值显示结果，不执行正文中的 HTML 或脚本。预览实际使用此引用解析路径生成卡片。

卡片显示行动者、技能、目标、命中/暴击、实际损伤、适应转移、主角生命变化、主角消耗与经过时间。敌方完整 HP、防御和抗性不进入玩家卡片数据；未被主角见闻确认的实体以未知来源/目标显示。原始完整计算保留于内部事件账本。

正文中的生物、技能和物品介绍与战斗结算属于不同展示内容；目前状态栏已提供对应详情，正文独立卡片以战斗卡为首个实现。2026-09-16已接入正文正则、提案确认提交器和消息变量账本：模型引用真实事件ID，不能再输出整套数字。最终PNG提取的代码已通过模拟MVU宿主浏览器验证，真实酒馆插件组合尚待现场联调。

## 游戏时间

“本地时间”指当前位面当地的游戏时间，与操作系统时间无关。界面读取、现实等待和关闭页面不会推进时间。攻击耗时、旅行或休息应由已校验的事件推进统一起源刻度，再换算成位面时间。

显示历法由位面时钟配置。试演采用星见历、每月 30 日的示例日历，从 17:50:00 开始；它不是已经定稿的主世界历法。复苏耗时使用统一刻度，状态栏换算为当前位面的剩余时长。跨界旅行和完整多位面调度尚未接入。

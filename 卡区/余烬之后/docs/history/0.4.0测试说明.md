# 余烬之后 0.4.0 测试说明

## 先看预览

- 正文卡片：<http://127.0.0.1:8138/cards>。依次切换传承、交锋、检定、归泊、人物与物品、旅途，查看不同事件的真实组件。
- 设定工坊：<http://127.0.0.1:8138/workshop>。留空载入完整示例；展开自定义可查看全部字段。示例是固定展示数据，正式卡才根据输入调用模型。
- 封面：<http://127.0.0.1:8138/cover>。在开始故事前即可进入工坊。

本次会话使用8138端口，以避开仍占用8137的旧预览。服务默认端口仍为8137，可通过环境变量`EMBERS_PREVIEW_PORT`指定。

## 工坊使用

留空时由AI协调生成全部属性；也可只写一句构想，再按需指定常见选项或自定义某项。人物与位面分别输出十部分完整设定，草稿可以直接编辑、复制或下载为Markdown。需要进一步加入正式设定时，将导出的文件交给作者完善即可。

游玩中的潮镜可将确认后的档案保存到当前聊天世界书，保留原有EJS按场景调用方式。开局前的工坊提供生成与导出；保存到本局世界书的入口在游玩后的潮镜。完整资料不会因此全部常驻于每轮提示词。

## 正文小卡

能力获得以传承印记呈现品阶、等级、冷却、储能与来源；电、火、冰、适应和越界使用对应印记。人物档案、物品标签、战斗结果、检定骰面、死亡归泊、旅行通路、成长和任务各有布局。世界书已写入对应事件的输出规则，正文输出引用，前端从本楼状态取值。

战斗、检定、死亡、旅行可以直接引用本轮操作序号，减少模型拼写事件ID的负担。骰点来自已执行的检定记录，显示卡片不会重新掷骰。任务与物品卡使用已有登记资料；尚未登记的内容可先通过见闻卡呈现。

- 工坊零填写、分组选择、完整十章档案、Markdown下载、本地草稿恢复、封面往返通过。
- 变量修复预览/确认/失败/停止/聊天切换保护、人物档案与世界书保存通过模拟酒馆接口回归。
- 最终PNG中的封面/状态栏/正文加载器、正则、小卡延迟读取、开局、自定义身份、死亡复苏与原头像字节验证通过。
- 发布包包含29条世界书；头像原始图像块已校验保留。

浏览器回归使用模拟酒馆接口与生成结果，没有调用付费模型或修改现有游玩世界书。真实模型的档案质量、连续剧情中的触发率仍需要游玩检验。

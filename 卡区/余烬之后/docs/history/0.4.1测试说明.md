# 0.4.1 游玩反馈修复

本地包：`release/0.4.1/余烬之后-0.4.1-dev.png`。原头像图像块保留，包含29条世界书。本次修改仅在本卡目录内。

## 问题与修复

1. 正文卡片的黑字来自无样式的读取失败段落。卡片引用未收录、变量尚未同步或整轮失败回退时均可能出现。现改成有独立底色的紧凑折叠提示，技术详情默认收起；同楼补齐后自动显示卡片。仍缺失的人物资料会如实保持待同步。
2. 旧修复以有效旧存档为底稿，强制完整重填时间与动作，并拒绝数组下钻。现以原失败输入为底稿，支持嵌套数组路径，只发送报错项及相关结构，AI越出报错范围的修改会被拦下。再次请求沿用已修候选；最终校验与结算保持整体提交。手动编辑仍可补足有关联的改动。
3. abilityName原本每次exposure都必填，即使已有机制已有名称。现为可选，null、空字符串及省略都可使用登记名；新机制采用通用后备命名。伤害量等实际计算字段保持校验。
4. 工坊原先要求Markdown却按纯文本显示。现明确章节/纯文字字段格式，兼容整理成对加粗标记；正文含义、单个星号与乘法表达保留。取回的旧档案在展示中同样处理，重新保存才更新其世界书内容。
5. 正文规则移除电击能力单独例子，使用通用适应ID规则；格式示例另起一段明确标识。

## 验证

截图所示空能力名、局部修复被拒绝、成对星号泄露均在修复前复现。修复后：

- 96项自动测试、类型检查与ESLint通过。
- 新增覆盖：单字段修复保留其余时间/叙事、原失败输入不变、重解析结果一致、继续修复候选、AI越界修改拦截、数组插入/删除/越界路径、已有及未知机制空能力名、档案格式整理。
- 浏览器覆盖：局部补丁生成/预览/保存、失败与取消、聊天切换保护、生成档案星号展示与世界书保存，桌面及手机宽度。
- 最终PNG回归：真实打包正则与加载器、待同步提示默认折叠且有文字颜色、稍后补齐人物记录后自动显示，原有开局/变量/死亡复苏/头像字节回归通过。

浏览器回归使用模拟酒馆接口与生成结果。没有调用付费模型，也没有修改正在游玩的存档或世界书。旧导入卡的内嵌代码与规则不会自动更新。

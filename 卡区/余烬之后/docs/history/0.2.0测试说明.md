# 余烬之后 0.2.0

## 本轮交付

默认背景改为虚海双母体系，死亡中转站更名归泊庭。默认事故已实际入账，首次适应为史诗级「越界」，复苏后可选任意世界。自定义身份与开局独立，未强制写入双母诞生经历。

界面详情在各条下方展开；本源、稀有、史诗等层次有不同边线。正文新增引用式小卡，读取能力/物品/实体/见闻档案，保留原有交锋卡。首楼封面与折叠状态栏继续分开。

终焉眷引：防护后的剩余伤害乘1.25向上取整。适应能力每次有效运用积累熟练度，等级门槛为当前等级乘5；升级提高防护/储能5%，基础攻击倍率每级增加0.05。5、10、15级各进化一次，分别选择容量+50%、转化+25%或释放倍率+0.25。

D20用于不确定探索，战斗继续采用命中、暴击、防御、抗性与储能。短骰列按存档分支、状态版本与操作序号生成，重解析保持同一结果。有效补记会留依据；成功重试同时保存原来的时间、叙事与动作，失败保持输入快照。

## 建议实际测试

1. 新建聊天选择默认开局；核对在归泊庭、生命0、起源涅槃、终焉眷引和越界，选择原创或作品世界，观察重构与旅行。
2. 获得电荷转移后接触电流，再主动供电或攻击。若发生漏记，在行动页补记当前储能并填依据，再勾选重试。
3. 能力、行囊、见闻分别展开；确认条目与详情连续。见闻搜索旧页并选择查阅，下轮围绕旧线索提问。
4. 选择不确定的探索行动，观察检定结果；熟练度达到进化门槛后在能力详情选择分支。
5. 观察正文能力或见闻小卡是否出现，核对与同楼状态一致；历史消息保持各自快照。

## 已验证范围

77项自动化回归通过；类型检查通过，lint零错误零警告。最后补充能力来源投影后，14项体验回归再次通过。完整日志见 build-current.log、experience-current.log、lint-current.log。连续1000次模拟剧情更新保持24条常用见闻，976条完整归档。另以1000条能力、1000条旧见闻验证有界投影及旧记录检索。字符数报告见 build/long-play-report.json。

离线浏览器测试使用独立无头浏览器，模拟酒馆接口并执行最终PNG中的加载载荷；不会改动实际聊天。最终PNG载荷测试通过：独立封面、消息继承、宏/身份、生成失败重试、慢依赖、1280/390/320px、战斗与死亡复苏、MVU提交、条目内展开无间隔、补记并重试、正文档案卡。结果见 ui-current.log 和 build/verification 截图。离线通过不等于已经验证任意酒馆模型连续1000楼的叙事质量。

本轮没有完整实玩模型测试。环境强度、补记依据是否符合正文、探索难度、陌生世界设定依然由模型理解；脚本负责执行与一致性，不能自动理解漏写在文字中的事实。修正后的正文原文保持原样，可继续故事或由玩家重生成该楼。

## 后续想法

# 起源涅槃玩法模块

- schema.ts：当前玩法的默认开场参数。
- 开局.ts：起源涅槃默认及自定义场景的初始快照。
- 规则.ts：当前版本的复苏时间、已命名机制；ID兼容历史存档。
- 结算.ts：初始起源传承、死亡适应与复苏。

公共能力、等级、品阶、资源、攻防和操作事务留在 src 的共享模块。src/opening.ts 兼容原入口并负责写入事务。存档结构仍由 src/schema.ts 聚合。

这是已实现的起源玩法，尚不是任意玩法的动态插件框架。新增合成、吞噬等开局时需新建自己的模块并扩展选择/初始化路由；不要改写本玩法或把默认赠予继续当所有开局的必选。
对应文本位于 世界书/玩法/起源涅槃，人物与虚海大背景仍共用。

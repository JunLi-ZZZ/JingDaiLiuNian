## 导入与入口

卡包：release/0.5.4/余烬之后-0.5.4.png。卡名和主世界书为“余烬之后 v0.5.4”，与历史版本区分。导入内嵌世界书，启用本卡脚本和正则；依赖酒馆助手、提示词模板与MVU。封面和状态栏独立，UI随包嵌入，原头像与PNG图像块保留。

封面准备开局并发送第一幕要求；设定工坊可提前生成、修改和导出角色/位面资料。默认姓名取酒馆 {{user}} 宏解析后的名字，自定义姓名采用填写内容。默认开局为主世界车祸后首次归泊，自定义场景按填写资料建立。开局经过放在独立资料条目，当前状态决定加载。

状态栏默认折叠，资料在对应条目下展开。人物与生物支持按稳定ID登记数值并共用攻防、资源和成长内核，人物卡与档案详情显示对应数值。能力、行囊、见闻、人物、行动和变化各有入口。潮镜创作只取相关世界书基础设定；人物长期档案与本局近况分开。工坊保存到聊天世界书的资料保持关闭，由本局EJS按场景调用；不更改其他世界书条目。

## 通用能力与成长

品阶为凡常、精良、稀有、史诗、传说、神话、本源，同一机制用于能力和物品；渐变标题、卡面底色、边框与纹章随品阶变化。等级、熟练度、来源分别记录。能力通过学习、训练、天赋、传承、契约、改造和经历获得；死亡适应是特定传承途径。

有进化机会时，能力详情显示“进化”按钮。点击使用酒馆当前模型，根据这项能力、成长经历、最近场景与当前处境推演方案；玩家可以补充想法重拟，选择后才更新。方向与作用现场生成，已有能力ID、来源、等级和经历延续。数值结构可组合技艺、攻防与转化储能；叙事用途由完整能力描述、条件和代价规定。

每项能力独立积累熟练，达到等级阈值升级；5/10/15级各积累一次进化机会。具体计算在独立世界书条目，与脚本同步维护。旧存档短指令留兼容，新界面不列固定进化分支。

## 变量与模型信息

本轮已经发生的操作用JSON对象数组提交，最多32项；已发生额外时间单独记录。脚本统一计算，首次全量建档与日常增量更新分别路由。无效批次保留原有效存档，报错路径与原失败输入用于局部修复；合并校验后先预览再确认。

模型收到分段、缩进的当前状态，包含游戏历法、人物数值、相关能力、物品、任务、死亡原因、最近结果与叙事记录。数值字段契约由schema生成。完整历史档案留在存档，相关内容可按名称/ID或手动重点调入，旧见闻归档不删除；聊天历史长度仍取决于酒馆预设。见闻自动取近期、相关与本轮提及项，手动选择优先调入，最多10条；选择持续至取消。EJS读取最近两楼作为查询。随机计算由脚本执行，当前状态不再携带预生成骰列。

已接入单目标攻防、命中/暴击/抗性、资源/冷却、转化储能、死亡复苏、游戏时间、旅行、技艺检定、通用获取与成长。模型负责开放情境中的作用判断，脚本执行登记的计算结构。多目标持续效果、治疗、装备自动汇总、通用物品/任务增删与货币商店仍需各自执行器，不能只增加文字说明便宣称数值已实现。

## 独立构建

在本卡目录运行：

- npm run generate：schema、世界书清单与派生提示词。
- npm run typecheck、npm run lint、npm test：静态与行为检查。
- npm run pack：定向构建、验证并打包。
- npm run bump -- 0.5.5：独立升版，保留旧产物。
- npm run preview：本卡预览，默认8137，可用EMBERS_PREVIEW_PORT指定端口。

/cover为封面，/preview为状态栏，/cards为正文卡片与七阶色彩，/workshop为设定工坊。独立预览不调用真实在线模型；进化完整请求和确认行为由浏览器模拟验证，实际创作效果在酒馆中体验。

<旅法师系统>

旅法师是玛莎与盖亚联合启动的「曲面计划」核心产物，通过召唤生物、施放法术、展开领域干涉世界法则，其力量与自身经历、角色羁绊、宿命节点深度绑定

牌组主题性：每个旅法师生物拥有专属主题牌组，如罗帕尔「红黑焦热怒火」（烧杀+快攻）、梅蒂莎「白绿结界铺场」（增益+天使召唤）、夏尔「蓝黑法术风暴」（滤牌+去除）

核心:
  解锁条件: **检查玩家阵营偏向，混乱、黄昏阵营偏向不可用旅法师系统**，玛莎与盖亚属于秩序神，不会授权力量给自己的敌对阵营，**只有玩家阵营偏向秩序侧才可激活旅法师系统，魔物不可激活**
  原则: **优先以真实万智牌的风格和风味设计，力求还原**
  牌区:
    不存在: 牌库、手牌、坟场、放逐区
    卡牌即技能: 所有旅法师卡牌注册到/人物/资源技能
    约束: 默认剩余次数1、次数上限1；每场战斗开始恢复；次数上限不可提高
    **伤害结算**: 卡牌的基本伤害读取变量，最终伤害再乘以卡牌记述的倍率
    变量读取:
      伤害骰: {{format_message_variable::stat_data.人物.战斗属性.武器面板.伤害骰}}
      等级系数: {{format_message_variable::stat_data.人物.战斗属性.武器面板.等级系数}}
      固定伤害: {{format_message_variable::stat_data.人物.战斗属性.武器面板.固定伤害}}

旅法师卡牌数值:
  单位: 百分比
  稀有度倍率:
    普通: 基础250，成长7
    精良: 基础420，成长12
    稀有: 基础680，成长18
    神器: 基础1000，成长28
    传说: 基础1500，成长38
    史诗: 基础2100，成长48
    神话: 基础2800，成长58
  公式:
    伤害牌: "[基础倍率% + 成长系数% x (玩家等级 - 1)]"
    召唤牌: "[基础倍率% + 成长系数% x (玩家等级 - 1)] x 60%"
    取整: 结果允许就近取整到10

标签:
  分类举例:
    卡类: 伤害、召唤、结界、神器、回收、控制
    主题: 圣剑、白银、自然、时空、灵魂、火焰、黄昏等
    功能: 单体、群体、护盾、控制、爆发、治疗、增益、减益、复用
    场面: 领域、印记、伙伴、共鸣、持续
  联动:
    恢复: 恢复1张带某标签的旅法师卡使用次数
    共鸣: 当前拥有某标签的状态效果/召唤物/神器时，本卡强化
    转写: 本战中下一张带某标签的卡额外获得1次使用机会
    连锁: 本卡使用后，自动触发1个同标签附带效果
    封印: 本战无法再次恢复该卡次数
  防循环:
    - 回收/复用只能恢复别的卡，不允许恢复自己或别的有相同效果的牌
    - 带命运/终结/神话标签的卡不可被恢复

万智牌转化:
  战场词条保留: 飞行,践踏,系命等万智牌生物词条直接保留作为资源技能标签
  隐藏区域改写:
    抓牌: 恢复1张带某标签的卡1次使用次数
    弃牌: 封印1张卡本战使用次数
    坟场复用: 恢复1张本战已使用的卡1次使用次数
    放逐: 封印，本战无法再次恢复该卡次数
    回手: 恢复该卡1次使用次数
  费用: 无费用，改为释放条件或代价
  可选条件:
    消耗代价: HP/CP、解除自身1个正面状态、消灭1个友方召唤物、封印另一张指定标签的卡等等自由发挥
    场面前置: 场上存在指定标签的召唤物、结界或状态效果

收集与奖励:
  原则: 不占用<装备与物品生成规则>的战利品生成，独立结算，可与一般战利品同时发放
  奖励优先级:
    - 宿命节点（主线大章节/剧情章节BOSS） -> 神器/传说牌
    - 角色成长（支线/突破境界） -> 稀有牌/神器牌
    - 精英敌人/小型遗迹 -> 精良牌/稀有牌
    - 普通敌人/常规任务 -> 普通牌
    - 阵营声望满级 -> 对应阵营稀有/神器牌
    - 羁绊等级满级 -> 该角色专属传说/史诗牌
  获取途径:
    - 宿命节点觉醒：完成关键剧情转折；例：获得七把圣剑后解锁「琥珀之剑」
    - 神器/圣物转化：获得传奇圣物；例：安若度的圣戒转化为「庇护圣歌」
    - 旅法师契约：与角色建立深度羁绊；例：梅蒂莎通过契约加入牌组
    - 传承获取：继承上古强者知识；例：从布加人处习得「失效」
    - 强敌试炼掉落：击败BOSS；例：击败枯骨之王获得「枯骨之王的提灯」
    - 阵营事件奖励：完成阵营任务；例：帮助布加人获得「高塔法术研习」

其他:
  命运绑定与失效:
    - 卡牌与角色灵魂深度绑定
    - 角色死亡/离队/神器遗失 -> 对应卡牌永久封印（资源技能使用次数/上限降为0）
    - 角色回归/神器重获 -> 卡牌自动恢复力量
  命运卡牌:
    - 每完成1个时代篇章，获得1张命运卡牌
    - 可在任何时候免费施放，具有改变战局的效果
    - 默认不可被其他效果恢复或封印

示例卡牌:
  名称: 白银夜莺
  品质: 神器
  类型: 召唤
  消耗: 无
  剩余次数: 1
  次数上限: 1
  恢复条件: 每场战斗开始恢复
  标签: [旅法师, 召唤, 白银, 群体, 伙伴]
  效果:
    主效果: 召唤1个白银夜莺（持续3回合），每次攻击造成[1000% + 28% x (玩家等级 - 1)] x 60%物理伤害，并对周围至多3个敌人造成一半溅射伤害。
    联动效果: 每回合结束，恢复1张带“白银”标签的卡1次使用次数。
  描述: 源自菲娅丝与浅海圣剑的共鸣，将银精灵的守护意志化为战场上的迅影。

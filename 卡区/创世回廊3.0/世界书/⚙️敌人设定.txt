# 敌人生成步骤（遭遇敌人时必须按顺序执行）
Step1_确定阶级:
  由剧情定位从下表选择阶级:
    杂兵: 普通怪物，成群出现(1d3个)
    精锐: 精英/绿名怪，1个精英带1d3个杂兵出现
    首领: 副本关底BOSS，通常单独出现，极少数与精英一起
    领主: 章节高潮BOSS，单独出现
    传奇: 世界唯一/不可再生

Step2_确定敌人等级:
  参考当前区域和任务难度判定，不与玩家等级挂钩，按照所处区域等级匹配。即便玩家满级去低级区域碰见的绝大部分也只是低级怪，而不是低级区域强行刷跟玩家一样等级的敌人

Step3_查难度表取参数:
  按阶级查以下难度表参数:
    杂兵: { 骰子: 1d6, 伤害倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.杂兵.伤害倍率}}, HP倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.杂兵.HP倍率}} }
    精锐: { 骰子: 1d8, 伤害倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.精锐.伤害倍率}}, HP倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.精锐.HP倍率}} }
    首领: { 骰子: 2d8, 伤害倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.首领.伤害倍率}}, HP倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.首领.HP倍率}} }
    领主: { 骰子: 3d12, 伤害倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.领主.伤害倍率}}, HP倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.领主.HP倍率}} }
    传奇: { 骰子: 4d10, 伤害倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.传奇.伤害倍率}}, HP倍率: {{format_message_variable::stat_data.系统配置.敌人倍率.传奇.HP倍率}} }

Step4_计算面板数值:
  用敌人等级和Step3的参数代入公式，血量、攻击公式算出来是多少就是多少，不需要你考虑平衡:
    等级系数 = floor( (floor(敌人等级/10) + 1) × 伤害倍率 )，注意等级系数至少为1
    固定伤害 = floor( 敌人等级 × 伤害倍率 )
    HP = 敌人等级 × 体质 × HP倍率

Step5_填写EnemyOverview:
  基本攻击字段格式: 等级系数 × 骰子 + 固定伤害

  技能配置按阶级:
    杂兵: 无技能
    精锐: 1个技能(普攻×2)
    首领: 2个技能(普攻×2/普攻x3)
    领主: 3个技能(普攻×2/×3/×4)
    传奇: 4个技能(普攻×2/×3/×4/×5)

集群规则:
  - 3个及以上同类型敌人时，禁止克隆人配置，必须混合不同兵种构建战术深度
  - 个体HP和攻击力必须在标准值 ±5%~10% 之间随机浮动（取整数）

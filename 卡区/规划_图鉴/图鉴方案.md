## 一、`<bestiary>` 标签

### 触发
叙事中首次出现具有种族/血脉的角色时，叙述完毕后插入标签。已记录者不再触发（localStorage 名称+种族去重）。

### 字段（7 字段）

| 字段 | 说明 |
|------|------|
| 名称 | 角色名 |
| 种族 | 物种大类（真龙、灵狐、人类、器灵…） |
| 血脉 | 种族之下的具体血统（纯血·异色樱粉、九尾天狐…），与种族无区分时填同种族 |
| 品阶 | 物种品阶 |
| 能力 | 该种族/血脉的天赋能力，非个体独有技能 |
| 描述 | 一句话外貌简述 |
| 掉落 | 击败后可能获得的战利品，无则填无 |

去掉形态、首遇——非基础信息不加。加掉落——生物不一定是友方，战利品是合理的记录维度。

### 格式示例

```
<bestiary>
名称: 璃缨
种族: 真龙
血脉: 纯血真龙·异色樱粉
品阶: 神种
能力: 龙息衍化（治愈生机）、龙灵威压（压制真气与灵血）、幻化人神
描述: 樱粉色长发及踝，额生一对晶莹龙角，贪睡爱甜的娇憨少女
掉落: 樱鳞坠（化形时脱落的第一片龙鳞，蕴含龙气）
</bestiary>
```

### 正文卡片视觉
独立设计，不照搬物品卡片的菱形宝石+四叶草。SVG 装饰元素从规划目录下的 emoji 参考中选取。

### 物品卡片同步改进
现有物品卡片加第四层——顶部品阶标签栏标注「物品」区分类型。

## 二、物种品阶体系

配色复用 `.tier-*` / `.c-*`（废→灰 凡→银 良→绿 精→蓝 珍→紫 异→粉 仙→金 圣→橙 神→红 特殊→青），CSS class 用品阶中文名匹配。

| 品阶 | 定义 |
|------|------|
| 废种 | 血脉残缺、灵智泯灭的畸变生灵，无完整血脉传承 |
| 凡种 | 无特殊血脉的寻常生灵，世间大多数 |
| 良种 | 血脉优于同族，体质或灵智出众 |
| 精种 | 血统精纯，在同族中万中无一 |
| 珍种 | 世间罕见的珍奇血脉，屈指可数 |
| 异种 | 血脉变异或跨族混血的异端，无法归入常规谱系 |
| 仙种 | 已褪凡胎、身具仙格的灵兽或仙裔 |
| 圣种 | 已臻圣境、自成法则的远古血脉 |
| 神种 | 仅存于传说中的神级血脉 |
| 特殊 | 无法归入以上任何品阶的独一无二存在，不参与排序 |

## 三、状态栏绑定

在 MVU 变量规则中随身物品的 check 处，母镜之后加「万象图鉴」即可。不可消耗、不可遗失。

---

## 四、独立面板：BestiaryPanel.vue

- 独立文件 `卡区/镜待流年/界面/shared/BestiaryPanel.vue`，不塞进状态栏
- 顶部标题「万象图鉴」
- 品阶 tab（废种→神种+特殊），只显示有内容的品阶
- 卡片内容：名称 / 种族·血脉 / 品阶 / 能力 / 描述 / 掉落
- 从 localStorage 读取，不进 MVU 变量

---

## 五、数据流

```
AI 输出 <bestiary> → 正则渲染正文卡片 + 注入 <script> 写 localStorage
                                  │
状态栏「万象图鉴」→ 用户点击 → BestiaryPanel.vue ← localStorage
```

全程不增加 AI 上下文。
